# Obby Wall Parkour - 4K

A 2D parkour obstacle course (obby) game with wall hopping and sticking mechanics!

## Features

- 🎮 **Wall Sticking**: Grab onto red walls and slide down slowly
- 🚀 **Wall Jumping**: Jump off walls to reach platforms
- 📍 **Checkpoints**: Save your progress at green checkpoints
- ⚠️ **Obstacles**: Avoid spikes and deadly traps
- 🎯 **Score System**: Earn points for reaching checkpoints
- 4️⃣ **4K Ready**: Optimized for high-resolution displays

## Controls

| Key | Action |
|-----|--------|
| **A** | Move Left |
| **D** | Move Right |
| **SPACE** | Jump |
| **Q** | Dash Left |
| **E** | Dash Right |

## Gameplay

1. Start on the left platform
2. Use wall hopping to navigate between walls and platforms
3. Avoid spike traps
4. Reach checkpoints to save progress (lose 50 points if you die)
5. Complete the level by reaching the yellow goal platform

## How to Play

1. Open `index.html` in your web browser
2. Use the controls above to navigate the course
3. Try to get the highest score!

## Game Mechanics

### Wall Sticking
- Run into a red wall at speed to stick to it
- Gravity is reduced while sticking
- Use SPACE to jump off and propel yourself across gaps

### Wall Jumping
- Jump at the right angle to reach distant platforms
- Chain wall jumps together for advanced movement

### Checkpoints
- Reach green checkpoints to set your spawn point
- Gain 100 points per checkpoint
- Lose 50 points if you die before reaching another checkpoint
